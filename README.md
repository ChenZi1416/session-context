# Session Context — 会话上下文存取

> 基于 WPS 云文档后端的 AI 会话上下文持久化技能，支持跨设备恢复。

在会话结束时保存当前对话的上下文摘要到 WPS 云文档，并在新会话中通过「特征码」一键恢复，无需重述整个对话历史。数据存储在云端，支持跨设备访问。

## 一键导入

在 WPS 灵犀技能管理页面，点击 **「+ 创建技能」** → **「从 GitHub 导入」**，粘贴本仓库链接：

```
https://github.com/ChenZi1416/session-context
```

系统会自动克隆仓库并读取根目录的 `SKILL.md` 完成导入，无需手动下载。

## 功能概览

| 功能 | 说明 |
|------|------|
| **保存上下文** | 将当前会话的关键信息（主题、决策、已完成任务、待办、偏好等）提炼为结构化摘要，上传到 WPS 云文档 |
| **恢复上下文** | 通过特征码从云端下载快照，自动注入新会话上下文，实现无缝继续 |
| **列出历史会话** | 查看云端所有已保存的上下文快照，含特征码、创建时间和云文档链接 |
| **删除上下文** | 定位指定快照的云文档链接，引导用户手动清理 |

## 工作原理

```
┌─────────────┐     JSON 摘要     ┌──────────────────┐     上传     ┌─────────────────┐
│  AI 会话结束  │ ───────────────▶ │ context_manager  │ ──────────▶ │  WPS 云文档      │
│  提炼摘要     │                  │   .py (save)     │              │ 会话上下文/       │
└─────────────┘                  └──────────────────┘              │ CTX-xxx.json    │
                                                                      └────────┬────────┘
                                                                               │
┌─────────────┐     特征码        ┌──────────────────┐     下载     ┌────────┴────────┐
│  新会话启动   │ ───────────────▶ │ context_manager  │ ◀────────── │  恢复快照         │
│  注入上下文   │ ◀─────────────── │   .py (restore)  │              └─────────────────┘
└─────────────┘    JSON 快照        └──────────────────┘
```

1. **保存时**：AI 回顾当前会话，按规范格式提炼摘要 → 写入临时 JSON → 调用 `context_manager.py save` 上传到 WPS 云文档 → 返回特征码
2. **恢复时**：用户在新会话中发送特征码 → 调用 `context_manager.py restore` 从云端下载快照 → AI 将摘要注入当前会话上下文 → 无缝继续协作

## 安装与配置

### 前置条件

- **WPS 账号**：需要已登录 WPS 灵犀的桌面环境，脚本通过 `kdocs` 模块自动复用已有会话凭据
- **wps-docs 技能**：本技能依赖 `wps-docs` 技能提供的 `kdocs.py` 模块，需确保 `wps-docs` 技能已安装

### 安装

1.在 WPS 灵犀技能管理页面，点击 **「+ 创建技能」** → **「从 GitHub 导入」**，粘贴本仓库链接：

```
https://github.com/ChenZi1416/session-context
```


2.在 WPS 灵犀技能管理界面，点击 **「+ 创建技能」** → **「上传技能」**，导入压缩包（session-context.zip）


3.或将压缩包解压后（解压到 session-context\）整体放入技能目录：

```
C:\Users\<用户名>\AppData\Roaming\WPS 灵犀\serverdir\target_skills\
```

### 配置

无需额外配置。`context_manager.py` 会自动在以下路径查找 `kdocs.py` 模块：

1. 环境变量 `SKILL_PATH` 指向的 `wps-docs/scripts/` 目录
2. 默认技能安装路径 `C:\Users\<用户名>\AppData\Roaming\WPS 灵犀\serverdir\target_skills\wps-docs\scripts\`

## 使用方法

所有操作通过 `context_manager.py` 脚本完成。

### 保存上下文

```bash
python scripts/context_manager.py save <summary_file.json>
```

**输入 JSON 格式：**

```json
{
  "title": "简短标题",
  "tags": ["标签1", "标签2"],
  "summary": "Markdown 格式的会话摘要全文"
}
```

**输出示例：**

```json
{
  "status": "saved",
  "feature_code": "CTX-20260808-A3F2",
  "cloud_file_id": "xxxxx",
  "cloud_link": "https://...",
  "message": "上下文已保存到 WPS 云文档"
}
```

### 恢复上下文

```bash
python scripts/context_manager.py restore <feature_code>
```

示例：

```bash
python scripts/context_manager.py restore CTX-20260808-A3F2
```

**输出示例：**

```json
{
  "status": "found",
  "feature_code": "CTX-20260808-A3F2",
  "created_at": "2026-08-08T14:30:00.123456",
  "title": "数据分析报告制作",
  "tags": ["Excel", "数据分析"],
  "summary": "## 会话主题\n...",
  "cloud_file_id": "xxxxx"
}
```

### 列出所有上下文

```bash
python scripts/context_manager.py list
```

返回云端所有已保存的上下文快照列表，包含特征码、云文档链接和创建时间。

### 删除上下文

```bash
python scripts/context_manager.py delete <feature_code>
```

> **注意**：WPS 云文档 API 不支持直接删除文件。该命令会定位到目标快照并返回云文档链接，需用户在 WPS 云文档界面中手动删除。

## 特征码格式

```
CTX-YYYYMMDD-XXXX
```

| 部分 | 说明 |
|------|------|
| `CTX-` | 固定前缀 |
| `YYYYMMDD` | 保存日期（如 `20260808`） |
| `XXXX` | 4 位随机十六进制字符（MD5 哈希取前 4 位，大写） |

**示例**：`CTX-20260808-A3F2`

特征码同时作为云文档文件名，确保全局唯一性。

## 存储架构

| 位置 | 路径 | 用途 |
|------|------|------|
| **云端** | WPS 云文档 → `会话上下文/` 文件夹 | 持久化存储，每份快照为 `CTX-YYYYMMDD-XXXX.json` |
| **本地缓存** | `~/.lingxi-context/` | 上传/下载时的临时文件，运行结束后自动清理 |

脚本自动解析 WPS 云文档中的「我的云文档」云盘（而非默认的「自动上传文档」云盘），确保用户可在 WPS 客户端中直接看到已保存的文件。

## 摘要结构规范

保存上下文时，AI 会按以下 Markdown 结构提炼摘要：

```markdown
## 会话主题
[一句话描述本次会话的核心主题]

## 关键决策
- [决策1]
- [决策2]

## 已完成
- [任务1] -> 产出: [文件路径]
- [任务2]

## 待办事项
- [待办1]
- [待办2]

## 用户偏好/纠正
- [偏好或纠正记录]

## 重要上下文
[恢复会话所需的任何额外背景信息]
```

> 摘要质量直接决定恢复效果。应聚焦于「恢复后继续工作需要知道什么」，而非逐条复述对话。产出的文件路径必须写完整路径，便于新会话中直接引用。

---

## 注意事项

- 快照摘要的质量直接决定恢复效果，应确保包含恢复会话所需的关键信息
- 如果会话较长，摘要应聚焦于「恢复后继续工作需要知道什么」，而非逐条复述对话
- 产出的文件路径必须写完整路径，便于新会话中直接引用
- 数据存储在用户 WPS 云文档中，可跨设备访问；如更换设备，在新设备登录同一 WPS 账号即可
- 本地缓存目录 `~/.lingxi-context/` 仅用于上传/下载时的临时文件，脚本运行结束后会自动清理
